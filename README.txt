QUICK START
1. Edit the wedding object near the bottom of index.html with names, dates, venue, maps link, and RSVP number.
2. Add three photos named 1.jpg, 2.jpg, 3.jpg inside photos/.
3. Add an MP3 named music.mp3 beside index.html. Only use audio you have permission to publish.
4. Create a PUBLIC GitHub repository called wedding-invitation.
5. Upload index.html, music.mp3, and the photos folder contents (photos/1.jpg etc). README.txt is optional.
6. Settings > Pages > Source: Deploy from a branch > main > /(root) > Save.
7. Visit https://YOUR-USERNAME.github.io/wedding-invitation/ after deployment.
NOTE: Browsers typically block unprompted autoplay with sound. The opening button starts music after a tap.
NOTE: All files uploaded to public GitHub Pages can be accessed publicly.
